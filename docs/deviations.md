## 申请流程

1. 在上表新增一行，写清楚 C++ 位置、RTL 位置、差异的精确含义；
2. 给出能复现的 trace 片段（周期号 + 字段）；
3. 评审人批准后才能合入；被拒绝的必须改成与参考模型一致。
